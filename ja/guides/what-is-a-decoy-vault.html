おとり保管庫とは？ 本当にあなたを守ってくれるのか

著者：Inertia Projects·公開日：2026年11月17日·最終更新日：2026年11月20日

結論

おとり保管庫とは、写真保管庫アプリの中にある 2 つ目の当たり障りのない保管庫で、別の PIN、パスワード、パターンで開きます。誰かにアプリを開けと迫られたらおとりを開けば、相手が見るのはプライベートな写真ではなく、普通の写真です。緊迫した場面では役に立ちますが、保証ではありません。いちばん効くのは、2 つ目の保管庫があることをアプリのどこにも匂わせない場合です。

保管庫アプリを使っていると知っている誰か（パートナー、親、国境の係官など）に「開けて」と言われた場面を想像してください。断ると、かえって事態が悪くなります。おとり保管庫があれば、3 つ目の選択肢が生まれます。開いて、当たり障りのないものを見せることです。ここでは、おとり保管庫の仕組み、アプリによってまったく違う 2 つの作り方、そして正直な限界を説明します。

おとり保管庫はどういう仕組み？

アプリが複数のコードを受け付けます。本当のコードは本当の保管庫を開き、2 つ目のコードは、普通の写真を入れておいた別の保管庫を開きます。見ている人からは、どちらもただアプリを開いたようにしか見えません。

偽の PIN、ダミーパスワード、偽の保管庫、サブパスコードなどと呼ばれることもあります。考え方は同じですが、作りの出来は大きく違います。

おとり保管庫には 2 つの種類がある

偽の画面を見せるだけのアプリもあれば、本当に別の、暗号化された保管庫を開くアプリもあります。

  • 偽の画面や偽のギャラリー。おとり用のコードで、同じアプリ内の別の画面が開きます。設定メニューにおとり機能の項目がそのまま見えていることも多く、設定を見る人やアプリをよく知る人には、おとりがあると気づかれるかもしれません。
  • 別の、暗号化された保管庫。コードごとに、独自の暗号鍵を持つ保管庫が開きます。ほかの保管庫はそのコードなしには読めないので、アプリは保管庫の一覧を表示できません。間違ったコードでは何も開きません。

2 つ目の種類のほうがはるかに見破られにくくなります。おとりの中に、ほかの何かを指し示すものが一切ないからです。

おとり保管庫にできないことは？

おとりで稼げるのは落ち着いた時間であって、本物の写真が消えるわけではありません。

  • 本物らしく見せる必要があります。空っぽのおとりや、写真が 3 枚しかないおとりは、かえって疑問を招きます。本物の、ありふれた写真を入れ、ときどき追加しましょう。
  • 本気の専門家には通用しません。ストレージの使用量、バックアップ、フォレンジックツールから、おとりで説明できる以上のデータがあると分かることがあります。
  • Face ID で見破られることがあります。Face ID で本物の保管庫が開くアプリでは、誰かが見ている前で Face ID を使うと気づかれます。迫られているときは Face ID ではなく、おとりのコードを使いましょう。
  • 法的な保護ではありません。デバイスのロック解除に関する法律は国によって違います。おとりはプライバシーのための道具で、何をすべきか、すべきでないかの助言ではありません。

おとり保管庫と緊急消去コードの違いは？

おとりは保管庫を隠し、緊急消去コードは保管庫を消します。3 つ目のコードで当たり障りのない保管庫を開くと同時に、ほかの保管庫を黙って削除するアプリもあります。写真を見られることは防げますが、写真は失われます。アプリがクラウドのバックアップまで消せる場合は、元に戻す方法はありません。

消去コードを設定するのは、写真を見られるくらいなら失ったほうがいい場合だけにしましょう。失っては困る写真なら、別の場所にもコピーを置いておきます。

必要になる前に、おとり保管庫をテストするには？

相手になったつもりで開き、本物の保管庫がばれる手がかりがないか探します。今 5 分かけておけば、あとで困らずに済みます。

  1. ロックした状態のアプリから、おとり専用のコードでおとりを開きます。
  2. 設定も含めて、すべての画面を確認します。別の保管庫の名前が出る、見えている数より多い項目数が表示される、「保管庫を切り替える」が出てくる、といったものは手がかりになります。
  3. バックアップやストレージの画面を確認します。おとりの中身よりずっと大きい合計容量は、疑いを招きます。
  4. Face ID を試します。本物の保管庫が開くなら、Face ID はオフのままにするか、緊張した場面でもおとりのコードを使えるよう練習しておきましょう。
  5. ときどき新しい写真を何枚か追加して、おとりの最新の項目が何か月も前のものにならないようにします。

おとり保管庫を上手に設定するには？

  1. 本物と取り違えないコードを選びます。ただし、緊張していても思い出せるものに。
  2. 本物の、ありふれた写真で埋めます：食事、旅行、スクリーンショット、ペットなど。3 枚ではなく数十枚を。
  3. ときどき使います。日付がすべて同じ日にならないように。
  4. 開く練習をします。一度か二度試しておけば、いざというときに迷いません。
  5. 何もばれないか確認します：おとりを開いて、設定、アルバム、件数を確認します。

私たちが開発している Noxium では、パターンごとに別の鍵を作るので、おとりは別の暗号化された保管庫です。Noxium は保管庫の一覧を表示せず、おとりの中におとりだと分かる印もなく、Face ID で開くのはメインの保管庫だけです。設定 › 保管庫 の「おとり保管庫を追加」から追加し、パターンを描きます。無料プランに 1 つ含まれています。

2 つ目のパターンで、当たり障りのない保管庫を

Noxium のおとり保管庫は、独自のパターンで開く別の暗号化された保管庫で、無料で使えます。Face ID では決して開かず、中には本物の保管庫を示すものは何もありません。Noxium のおとり保管庫の仕組みと、Pro の緊急消去パターンもご覧ください。

よくある質問

おとり保管庫は 2 つ以上持てる？

アプリによっては持てます。Noxium の無料プランにはおとり保管庫が 1 つ含まれ、Pro なら好きなだけ追加できます。ほかのアプリの掲載情報では、おとりのコードは 1 つだけという説明が一般的です。

写真保管庫アプリの偽 PIN とは何ですか？

プライベートな写真の代わりに、別の当たり障りのない写真を開く 2 つ目の PIN です。おとり保管庫の別名です。

おとり保管庫を使っていると気づかれますか？

気づかれる可能性はあります。設定におとり機能が表示されるアプリや、写真がほとんど入っていないおとりは見破られやすいです。普通の写真で埋めた、別の暗号化された保管庫であるおとりは、はるかに見破られにくくなります。

「非表示」アルバムにおとりはありますか？

ありません。「非表示」アルバムは Face ID か iPhone のパスコードで開き、当たり障りのない 2 つ目のバージョンはありません。

おとり保管庫はデュレスコードと同じですか？

違います。おとりは当たり障りのない保管庫を開くだけです。デュレスコードや緊急消去コードは、ほかの保管庫も削除し、元に戻せません。
