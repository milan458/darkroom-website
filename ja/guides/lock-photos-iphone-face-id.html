iPhone の写真を Face ID、パスコード、パターンでロックする方法

著者：Inertia Projects·最終更新日：2026年11月16日

結論

iPhone には、写真を Face ID でロックする標準の方法が 3 つあります。写真を非表示にして「非表示」アルバム（初期設定でロック）に入れる、「写真」アプリ全体で Face ID を必要にする、ロックしたメモに入れる、の 3 つです。どれも最後は iPhone のパスコードで開きます。パターンのように、パスコードとは別のロックが欲しいなら、写真保管庫アプリが必要です。

「写真」アプリには「このアルバムをロック」というボタンはありません。その代わり iOS 26 には、アルバム、アプリ全体、1 つのメモと、ロックする範囲の違う方法がいくつかあります。それぞれの設定方法と、実際に何がロックされるのか、そしてもっと強い守りが必要になるのはどんなときかを説明します。

「非表示」アルバムの写真を Face ID でロックするには？

写真を非表示にして、「非表示」アルバムの Face ID ロックがオンになっているか確認します。iOS 16 以降は初期設定でオンです。独立した保管庫と比べてどうなのかは、「非表示」アルバムと写真保管庫アプリの比較をご覧ください。

  1. 写真を非表示にする：「写真」で写真を長押しして 非表示 をタップします。まとめてなら 選択 をタップして写真を選び、詳細（…）から 非表示 をタップします。
  2. ロックを確認する：設定 › アプリ › 写真 で Face IDを使用（または Touch ID やパスコード）をオンにします。これで「非表示」と「最近削除した項目」の両方がロックされます。
  3. 必要なら：非表示アルバムを表示 をオフにすると、「コレクション」にアルバム自体が表示されなくなります。

「非表示」アルバムの場所、写真の見方と非表示の解除、iCloud や新しい iPhone での扱いは、iPhone の非表示の写真の完全ガイドにまとめています。

「写真」はほかのアルバムをロックできません。ロックがあるのは「非表示」と「最近削除した項目」だけです。しかもこのロックは iPhone のパスコードでも開くので、パスコードを知っている人なら誰でもアルバムを開けます（Apple サポート）。

「写真」アプリ全体をロックするには？

iOS 18 以降は、どのアプリでも開く前に Face ID を求めるように設定できます。

  1. ホーム画面で「写真」のアイコンを長押しします。
  2. Face IDを必要にする をタップして確定します。

これで「写真」は開くたびに Face ID を求めるので、ロック解除した iPhone を渡した相手にライブラリを見られずに済みます。ただし全部か無しかの二択です。1 日に何度もライブラリ全体のロックを解除することになり、パスコードでも開いてしまいます。

写真をメモに入れてロックするには？

写真をメモに追加して、そのメモをロックします。メモには iPhone のパスコードとは別のパスワードを設定でき、Face ID を近道として使えます。

  1. メモアプリで新しいメモを作成し、カメラボタンをタップして、ライブラリから写真やビデオを選ぶ項目を選びます。
  2. 詳細（…）をタップして ロック を選びます。
  3. 別のパスワードを使うなら、設定 › アプリ › メモ › パスワード でメモ用のパスワードを設定し、Face IDを使用 をオンにします。
  4. 元の写真を削除します。「写真」で削除し、さらに「最近削除した項目」からも削除します。

パスコードとは別にできる標準のロックはこれだけです。数枚の写真向きで、ライブラリ全体には向きません。アルバムがなく、長いビデオは扱いにくいからです。メモ用のパスワードを忘れると、Apple でもロックしたメモを復旧できません。

ほかの写真を見られずに 1 枚だけ見せるには？

アクセスガイドを使います。iPhone をいま開いているアプリに固定するので、相手はそのアプリから出られません。

  1. 最初に一度だけ 設定 › アクセシビリティ › アクセスガイド でオンにし、パスコードを設定します。
  2. 写真を開き、サイドボタンを 3 回押して 開始 をタップします。画面の一部を丸で囲んで、そこを無効にすることもできます。
  3. 終了するには、サイドボタンを 3 回押してアクセスガイドのパスコードを入力します。

画面のタッチを無効にしない限り、アクセスガイドでも「写真」の中でほかの写真へスワイプできてしまいます。写真全体を丸で囲むか、オプションで タッチ をオフにしましょう。

iPhone で写真をパターンでロックできる？

標準機能ではできません。iOS が使うのは Face ID、Touch ID、パスコードで、描くパターンのロックは保管庫アプリだけのものです。App Store の掲載情報や各社のサイトによると、Private Photo Vault、Vaultaire、Noxium などがパターンに対応しています。

パターンの強さは、その裏で何をしているかで決まります。普通のファイルの前に画面を 1 枚置くだけのアプリもあれば、パターンから暗号鍵を作るアプリもあります。信用する前に、そのアプリがパターンをどう使っているか確認しましょう（違いは暗号化された写真保管庫の仕組みで説明しています）。

私たちが開発している Noxium では、5×5 のプレートにある 25 本のボルトのうち 6 本以上を通るパターンを描きます。パターンは保存されません。Argon2id でパターンから保管庫を開く鍵を作り、すべての写真を iPhone 上で AES-256-GCM で暗号化します。Face ID で開けるのは便利のためのメインの保管庫だけで、おとり保管庫は決して開きません。

パスコードとは別のロック

Noxium は iPhone のパスコードとは別の、あなただけが知っているパターンで開きます。すべての写真は iPhone 上で暗号化されます。写真 150 枚、ビデオ 10 本まで無料。

よくある質問

iPhone で特定のアルバムだけをロックできますか？

できません。「写真」アプリがロックするのは「非表示」と「最近削除した項目」だけです。ほかの写真をロックするには、非表示にするか、ロックしたメモに入れるか、保管庫アプリを使います。

iPhone のパスコードとは別のパスワードで写真をロックできますか？

できます。方法は 2 つで、メモ用のパスワードを設定したロックしたメモか、独自の PIN、パスワード、パターンを持つ保管庫アプリです。

「写真」アプリをロックするとアプリは隠れますか？

隠れません。「Face IDを必要にする」は「写真」を開くときに Face ID を求めるだけで、アプリはホーム画面に残ります。

パターンロックは PIN より安全ですか？

それだけでは決まりません。大切なのは、コードが写真の暗号化に使われているか、そして推測にどれだけ時間がかかるかです。暗号鍵を作るのに使われる長いパターンやパスワードは、普通のファイルの前に置かれた 4 桁の PIN よりはるかに強力です。
