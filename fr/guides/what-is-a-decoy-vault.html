Guide · Coffres leurres

Qu’est-ce qu’un coffre leurre, et vous protège-t-il vraiment?

Par Inertia Projects·Publié le 17 novembre 2026·Mis à jour le 20 novembre 2026

En bref

Un coffre leurre est un deuxième coffre, anodin, dans une app de coffre photo, qui s’ouvre avec un autre NIP, mot de passe ou schéma. Si quelqu’un vous presse d’ouvrir l’app, vous ouvrez le leurre, et la personne voit des photos ordinaires plutôt que vos photos privées. Ça aide dans un moment tendu, mais ce n’est pas une garantie : ça marche le mieux quand rien dans l’app ne révèle qu’un deuxième coffre existe.

Imaginez quelqu’un qui sait que vous utilisez une app de coffre (un conjoint, un parent, un agent à la frontière) et qui vous dit : « Ouvre-la. » Refuser envenime les choses. Un coffre leurre vous donne une troisième option : l’ouvrir et montrer quelque chose d’anodin. Voici comment fonctionnent les coffres leurres, les deux façons très différentes dont les apps les construisent, et leurs vraies limites.

Comment fonctionne un coffre leurre?

L’app accepte plus d’un code. Votre vrai code ouvre votre vrai coffre. Un deuxième code ouvre un coffre distinct que vous avez rempli de photos ordinaires. Pour qui regarde, dans les deux cas, vous avez simplement ouvert l’app.

On l’appelle aussi faux NIP, mot de passe leurre, faux coffre ou code secondaire. L’idée est la même; la qualité de la mise en œuvre varie énormément.

Quels sont les deux types de coffre leurre?

Certaines apps affichent un faux écran; d’autres ouvrent un coffre vraiment distinct et chiffré.

  • Un faux écran ou une fausse galerie. Le code leurre ouvre une autre vue dans la même app, souvent avec un menu de réglages qui affiche encore l’option leurre. Quiconque fouille les réglages, ou connaît l’app, peut voir qu’un leurre existe.
  • Un coffre distinct et chiffré. Chaque code déverrouille son propre coffre avec sa propre clé de chiffrement. L’app ne peut pas afficher une liste des coffres, parce qu’elle ne peut pas lire les autres sans leurs codes. Un mauvais code n’ouvre tout simplement rien.

Le deuxième type est beaucoup plus difficile à démasquer, parce que rien dans le leurre ne pointe vers autre chose.

Qu’est-ce qu’un coffre leurre ne peut pas faire?

Un leurre vous fait gagner un moment de calme; il ne fait pas disparaître vos vraies photos.

  • Il doit être crédible. Un leurre vide, ou avec trois photos, attire d’autres questions. Mettez-y de vraies photos banales et ajoutez-en de temps en temps.
  • Il ne résiste pas à un expert déterminé. L’espace de stockage utilisé, les sauvegardes ou des outils d’analyse peuvent montrer qu’il y a plus de données que ce que le leurre explique.
  • Face ID peut le trahir dans les apps où Face ID ouvre votre vrai coffre pendant que quelqu’un regarde. Sous pression, utilisez le code leurre, pas Face ID.
  • Ce n’est pas une protection juridique. Les lois sur le déverrouillage des appareils varient d’un pays à l’autre. Un leurre est un outil de confidentialité, pas un conseil sur ce que vous devez ou ne devez pas faire.

En quoi un coffre leurre diffère-t-il d’un code d’effacement d’urgence?

Un leurre cache votre coffre; un code d’effacement d’urgence le détruit. Certaines apps offrent un troisième code qui ouvre un coffre anodin et, en même temps, supprime discrètement les autres. Ça empêche que les photos soient vues, mais elles sont perdues. Si l’app peut aussi supprimer la sauvegarde infonuagique, il n’y a pas de retour possible.

N’activez un code d’effacement que si perdre ces photos vaut mieux qu’elles soient vues, et gardez-en une copie ailleurs si vous ne pouvez pas vous permettre de les perdre.

Comment tester un coffre leurre avant d’en avoir besoin?

Ouvrez-le comme si vous étiez l’autre personne, et cherchez tout ce qui trahirait le vrai coffre. Cinq minutes maintenant vous évitent un mauvais moment plus tard.

  1. Ouvrez le leurre avec son propre code, à partir de l’app verrouillée.
  2. Parcourez chaque écran, réglages compris. Tout ce qui nomme un autre coffre, compte plus d’éléments que ce que vous voyez ou propose de « changer de coffre » vous trahit.
  3. Vérifiez les écrans de sauvegarde ou de stockage. Un total bien plus gros que le contenu du leurre attire les questions.
  4. Essayez Face ID. S’il ouvre le vrai coffre, laissez Face ID désactivé ou exercez-vous à utiliser le code du leurre sous pression.
  5. Ajoutez quelques nouvelles photos de temps en temps, pour que les derniers éléments du leurre ne datent pas de plusieurs mois.

Comment bien configurer un coffre leurre?

  1. Choisissez un code que vous ne confondrez pas avec le vrai, mais dont vous vous souviendrez sous le stress.
  2. Remplissez-le de vraies photos banales : repas, voyage, captures d’écran, animal de compagnie. Des dizaines, pas trois.
  3. Utilisez-le de temps en temps pour que les dates ne soient pas toutes du même jour.
  4. Pratiquez son ouverture une ou deux fois pour ne pas hésiter le moment venu.
  5. Vérifiez que rien ne le trahit : ouvrez le leurre et parcourez réglages, albums et nombres d’éléments.

Questions fréquentes

Peut-on avoir plus d’un coffre leurre?

Dans certaines apps. Le forfait gratuit de Noxium comprend 1 coffre leurre et Pro en ajoute autant que vous voulez; les fiches des autres apps décrivent en général un seul code leurre.

Qu’est-ce qu’un faux NIP dans une app de coffre photo?

Un deuxième NIP qui ouvre un autre ensemble de photos, anodines, au lieu de vos photos privées. C’est un autre nom pour un coffre leurre.

Quelqu’un peut-il voir que j’utilise un coffre leurre?

Peut-être. Les apps qui montrent l’option leurre dans les réglages, ou les leurres avec très peu de photos, sont faciles à repérer. Un leurre qui est un coffre distinct et chiffré, rempli de photos ordinaires, est bien plus difficile à démasquer.

L’album Masquées a-t-il un leurre?

Non. L’album Masquées s’ouvre avec Face ID ou le code de votre iPhone, et il n’en existe pas de deuxième version anodine.

Un coffre leurre est-il la même chose qu’un code de contrainte?

Non. Un leurre ouvre seulement un coffre anodin. Un code de contrainte ou d’effacement d’urgence supprime aussi vos autres coffres, sans retour possible.
