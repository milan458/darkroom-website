Guide · Verrouiller des photos

Verrouiller des photos sur iPhone avec Face ID, un code ou un schéma

Par Inertia Projects·Publié le 16 novembre 2026·Mis à jour le 18 novembre 2026

En bref

L’iPhone peut verrouiller des photos avec Face ID de trois façons intégrées : les masquer pour qu’elles aillent dans l’album Masquées (verrouillé par défaut), faire exiger Face ID à toute l’app Photos, ou les mettre dans une note verrouillée. Dans les trois cas, le code de votre iPhone ouvre aussi le verrou. Pour un verrou distinct de votre code, comme un schéma, il vous faut une app de coffre photo.

Il n’y a pas de bouton « verrouiller cet album » dans l’app Photos. iOS 26 offre plutôt quelques verrous qui agissent à différents niveaux : un album, toute l’app ou une seule note. Voici comment configurer chacun, ce qu’il verrouille vraiment et quand il vous faut quelque chose de plus solide.

Comment verrouiller des photos dans l’album Masquées avec Face ID?

Masquez les photos, puis vérifiez que le verrou Face ID de l’album Masquées est activé. Il l’est par défaut depuis iOS 16. Pour voir comment ça se compare à un vrai coffre, lisez l’album Masquées face à une app de coffre photo.

  1. Masquez les photos : dans Photos, maintenez le doigt sur une photo et touchez Masquer. Pour plusieurs, touchez Sélectionner, choisissez-les, touchez Plus (…), puis Masquer.
  2. Vérifiez le verrou : allez dans Réglages › Apps › Photos et activez Utiliser Face ID (ou Touch ID, ou le code). Ça verrouille à la fois Masquées et Supprimées récemment.
  3. Facultatif : désactivez Afficher l’album Masquées pour que l’album n’apparaisse plus du tout dans Collections.

Où se trouve l’album Masquées, comment voir et afficher de nouveau les photos, et ce qui leur arrive sur iCloud et sur un nouvel iPhone : photos masquées sur iPhone, le guide complet.

Photos ne peut pas verrouiller les autres albums. Seuls Masquées et Supprimées récemment ont un verrou. Et ce verrou accepte le code de votre iPhone : quiconque le connaît peut ouvrir l’album (Assistance Apple).

Comment verrouiller les photos masquées sur iPhone?

Activez Utiliser Face ID dans Réglages › Apps › Photos. L’album Masquées demande alors Face ID, Touch ID ou votre code à chaque ouverture.

  1. Ouvrez Réglages › Apps › Photos.
  2. Activez Utiliser Face ID (l’option Touch ID ou code sur les iPhone sans Face ID).
  3. Testez : dans Photos, ouvrez Collections › Utilitaires › Masquées. Face ID devrait être demandé avant que quoi que ce soit s’affiche.
  4. Masquez l’album lui-même, si vous voulez, en désactivant Afficher l’album Masquées dans les mêmes réglages.

Si l’album s’ouvre sans rien demander, l’interrupteur est désactivé. Les photos masquées se synchronisent quand même sur chaque appareil connecté à votre compte Apple avec Photos iCloud, et chacun a son propre réglage Face ID.

Quelle est la différence entre masquer et verrouiller des photos?

Masquer retire une photo de votre photothèque principale; verrouiller met quelque chose devant. L’album Masquées fait les deux, mais son verrou, c’est le Face ID et le code de votre iPhone.

  • Masquée seulement : si l’interrupteur Face ID est désactivé, quiconque tient votre téléphone déverrouillé peut ouvrir l’album Masquées.
  • Masquée et verrouillée : il faut votre visage ou le code de votre iPhone.
  • Verrouillée avec un code distinct : une note verrouillée avec son propre mot de passe Notes, ou une app de coffre avec son propre schéma ou NIP, reste fermée même pour qui connaît votre code.
  • Chiffrée avec une clé distincte : dans une app de coffre chiffrée, la clé vient du code du coffre, et les fichiers sont illisibles sans lui. Voyez comment fonctionnent les coffres photo chiffrés.

Peut-on verrouiller un seul album sur iPhone?

Pas dans Photos. iOS ne verrouille que Masquées et Supprimées récemment. Pour verrouiller l’album de votre choix, il faut une app de coffre qui verrouille album par album; dans Noxium Pro, n’importe quel album peut avoir son propre schéma, et l’album reste verrouillé dans le coffre ouvert tant que ce schéma n’est pas tracé.

Comment verrouiller toute l’app Photos?

Depuis iOS 18, vous pouvez faire exiger Face ID à n’importe quelle app avant qu’elle s’ouvre.

  1. Maintenez le doigt sur l’icône Photos à l’écran d’accueil.
  2. Touchez Exiger Face ID et confirmez.

Photos demande maintenant Face ID chaque fois qu’elle s’ouvre, ce qui empêche la personne à qui vous tendez votre iPhone déverrouillé de parcourir votre photothèque. Mais c’est tout ou rien : vous déverrouillez toute votre photothèque plusieurs fois par jour, et le code l’ouvre quand même.

Comment verrouiller des photos dans une note?

Ajoutez des photos à une note, puis verrouillez la note. Notes peut utiliser un mot de passe distinct du code de votre iPhone, avec Face ID comme raccourci. (Pour des notes qui ne s’ouvrent qu’avec un schéma de coffre, voyez les notes chiffrées de Noxium, l’app que nous développons.)

  1. Dans Notes, créez une note, touchez le bouton Appareil photo et choisissez l’option pour ajouter une photo ou une vidéo de votre photothèque.
  2. Touchez Plus (…), puis Verrouiller.
  3. Pour un mot de passe distinct, allez dans Réglages › Apps › Notes › Mot de passe, choisissez un mot de passe Notes et activez Utiliser Face ID.
  4. Supprimez les originaux de Photos, puis de Supprimées récemment.

C’est le seul verrou intégré qui peut être distinct de votre code. Il convient à quelques photos, pas à une photothèque : pas d’albums, et les longues vidéos sont peu pratiques. Si vous oubliez un mot de passe Notes distinct, Apple ne peut pas récupérer les notes verrouillées.

Comment montrer une seule photo sans qu’on fasse défiler les autres?

Utilisez Accès guidé. Il bloque l’iPhone dans l’app ouverte, et l’autre personne ne peut pas en sortir.

  1. Activez-le une fois dans Réglages › Accessibilité › Accès guidé et définissez un code.
  2. Ouvrez la photo, appuyez trois fois sur le bouton latéral et touchez Démarrer. Vous pouvez entourer des zones de l’écran pour les désactiver.
  3. Pour y mettre fin, appuyez trois fois sur le bouton latéral et entrez le code d’Accès guidé.

Accès guidé n’empêche pas de faire défiler les photos dans Photos, sauf si vous désactivez le toucher à l’écran : entourez donc toute la photo, ou désactivez Toucher dans ses options.

Peut-on verrouiller des photos avec un schéma sur iPhone?

Pas avec les fonctions intégrées. iOS utilise Face ID, Touch ID et des codes; un verrou par schéma tracé ne vient que des apps de coffre. Private Photo Vault, Vaultaire et Noxium, entre autres, offrent un schéma selon leurs fiches App Store et leurs sites Web.

Un schéma ne vaut que ce qu’il y a derrière. Dans certaines apps, il ouvre seulement un écran posé devant des fichiers ordinaires; dans d’autres, il sert à dériver la clé de chiffrement. Demandez comment l’app l’utilise avant de lui faire confiance (on explique la différence dans comment fonctionnent les coffres photo chiffrés).

Dans Noxium, l’app que nous développons, vous tracez un schéma sur au moins 6 des 25 boulons d’une plaque de 5×5. Le schéma n’est jamais enregistré : Argon2id en tire la clé qui ouvre votre coffre, et chaque photo est chiffrée sur l’iPhone en AES-256-GCM. Face ID peut ouvrir le coffre principal par commodité, mais jamais un coffre leurre.

Questions fréquentes

Quelqu’un peut-il ouvrir mon album Masquées sans Face ID?

Oui, s’il connaît le code de votre iPhone : le verrou se rabat sur lui. Si « Utiliser Face ID » est désactivé dans les réglages de Photos, rien n’est demandé du tout.

Masquer une photo la chiffre-t-il?

Pas plus que n’importe quelle autre photo. L’iPhone chiffre son stockage dans son ensemble, et masquer ne fait que déplacer la photo dans un album verrouillé, sans clé distincte.

Peut-on verrouiller un album précis sur iPhone?

Non. L’app Photos ne verrouille que les albums Masquées et Supprimées récemment. Pour verrouiller d’autres photos, masquez-les, mettez-les dans une note verrouillée ou utilisez une app de coffre.

Peut-on verrouiller des photos avec un autre mot de passe que le code de l’iPhone?

Oui, de deux façons : une note verrouillée avec un mot de passe Notes distinct, ou une app de coffre avec son propre NIP, mot de passe ou schéma.

Verrouiller l’app Photos la cache-t-il?

Non. « Exiger Face ID » demande seulement Face ID à l’ouverture de Photos. L’app reste sur votre écran d’accueil.

Un verrou par schéma est-il plus sûr qu’un NIP?

Pas forcément. Ce qui compte, c’est si le code sert à chiffrer les photos et à quel point il est lent à deviner. Un long schéma ou mot de passe qui sert à dériver une clé de chiffrement est bien plus solide qu’un NIP de 4 chiffres posé devant des fichiers ordinaires.
