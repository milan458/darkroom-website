Album Masquées ou app de coffre photo : lequel vous faut-il?

Par Inertia Projects·Mis à jour le 27 novembre 2026

En bref

L’album Masquées d’Apple est gratuit, intégré et verrouillé par Face ID, ce qui suffit pour garder des photos à l’abri des regards distraits. Mais il s’ouvre avec le code de votre iPhone, n’a pas de leurre et se synchronise sur tous les appareils de votre compte Apple. Une app de coffre photo comme Noxium ajoute un code distinct, un chiffrement avec une clé que vous seul détenez et un leurre pour quand on vous force à déverrouiller.

La plupart des gens essaient d’abord l’album Masquées, et pour beaucoup, ça suffit. Cette page le compare point par point avec une vraie app de coffre, en prenant Noxium, que nous faisons, comme exemple. Nous disons clairement quand l’album Masquées est le meilleur choix. Les détails d’Apple viennent de ses propres pages d’assistance, vérifiées le 15 novembre 2026; pour l’album seul, lisez l’album Masquées de l’iPhone est-il privé?

Qu’est-ce que l’album Masquées fait bien, et qu’est-ce qui lui manque?

L’album Masquées est l’espace privé le plus simple d’un iPhone. Toutes ses limites viennent d’un seul fait : il fait partie de votre photothèque habituelle, derrière votre code habituel.

Ce que l’album Masquées fait bien

  • Il est gratuit et déjà là. Touchez longuement une photo, puis touchez Masquer. Rien à installer, rien à payer.
  • Verrouillé par défaut. Depuis iOS 16, l’album Masquées et Supprimées récemment demandent Face ID, Touch ID ou votre code.
  • Vous pouvez cacher l’album lui-même. Désactivez Réglages › Apps › Photos › Afficher l’album « Masquées » et il disparaît des Collections.
  • Pleine qualité, tout Photos. Les photos masquées gardent leurs originaux, retouches, Live Photos et métadonnées, et vous pouvez les retoucher ou les partager comme d’habitude.
  • Sauvegardé avec tout le reste par Photos iCloud, et chiffré de bout en bout si vous activez la protection avancée des données.

Ce qui lui manque

  • Votre code l’ouvre. Quiconque connaît le code de votre iPhone, ou vous a vu le taper, peut ouvrir l’album Masquées. Face ID est une commodité, pas un deuxième verrou.
  • Aucun leurre. Si quelqu’un vous force à déverrouiller le téléphone, il n’y a rien d’inoffensif à montrer à la place.
  • Il se répand sur vos autres appareils. Avec Photos iCloud activé, les photos masquées sont sur chaque iPad et Mac connecté à votre compte Apple, y compris un iPad familial partagé.
  • Apple détient les clés iCloud, sauf si vous activez la protection avancée des données.
  • Photos seulement. Il n’y a pas de place pour des notes ou des documents privés.

En quoi une app de coffre diffère-t-elle de l’album Masquées?

Un coffre ajoute un verrou distinct et sa propre clé de chiffrement. Ça change qui peut entrer, pas seulement qui voit une vignette.

Un code distinct

Noxium s’ouvre avec un schéma sur une plaque de 5×5 boulons, qui n’a rien à voir avec le code de votre iPhone. Quelqu’un qui connaît votre code peut déverrouiller le téléphone, mais pas ouvrir le coffre.

Une clé que vous seul détenez

Chaque photo, vidéo et note de Noxium est chiffrée sur l’iPhone en AES-256-GCM, avec une clé tirée de votre schéma. Les noms, dates et lieux sont aussi chiffrés. L’album Masquées repose sur le chiffrement de l’iPhone, qui se déverrouille avec le code. Voyez le chiffrement sur l’appareil.

Ce qui se passe dans iCloud

Les photos masquées sont dans Photos iCloud avec le reste de votre photothèque. Avec la protection standard d’iCloud, Apple peut les déchiffrer; avec la protection avancée des données activée, elle ne le peut pas. La sauvegarde de Noxium est chiffrée sur l’iPhone avant l’envoi dans les deux cas, et va dans son propre espace de votre iCloud, pas dans Photos iCloud.

Leurres

Dans Noxium, un deuxième schéma ouvre un coffre leurre distinct qui a l’air d’un Noxium ordinaire. L’album Masquées n’a rien de tel. Notre guide sur les coffres leurres explique quand ça aide.

Commodité

Ici, l’album Masquées l’emporte. Il est gratuit, il fait partie de Photos et il garde vos retouches, la recherche et le partage. Un coffre, c’est une app de plus et un code de plus à retenir.

Lequel utiliser?

  • Utilisez l’album Masquées si vous voulez seulement sortir des photos de votre photothèque principale et que personne autour de vous ne connaît votre code. Activez la protection avancée des données pour des Photos iCloud chiffrées de bout en bout.
  • Utilisez une app de coffre si des gens autour de vous connaissent votre code, si vous partagez un iPad ou un Mac, si on pourrait vous forcer à déverrouiller votre téléphone, ou si vous voulez aussi garder des notes privées.

Beaucoup de gens utilisent les deux : l’album Masquées pour ce qui est simplement personnel, un coffre pour ce qui doit rester privé. Pour toutes les options, voyez toutes les façons de cacher des photos sur iPhone.

Comment déplacer des photos de l’album Masquées vers un coffre?

Ramenez-les dans la photothèque, importez-les dans le coffre, puis supprimez-les de Photos et de Supprimées récemment.

  1. Ouvrez l’album Masquées. Dans Photos, touchez Collections, faites défiler jusqu’à Utilitaires › Masquées, touchez Afficher l’album et déverrouillez-le avec Face ID ou Touch ID.
  2. Affichez les photos. Touchez longuement une photo, puis touchez Afficher. Elle revient dans votre photothèque en pleine qualité.
  3. Importez-les dans Noxium avec Réglages › Réglages de l’app › Proposer la suppression dans Photos activé, pour qu’il propose de les supprimer de Photos après l’importation.
  4. Videz Supprimées récemment dans Collections › Utilitaires › Supprimées récemment. D’ici là, les copies sont encore sur le téléphone et dans Photos iCloud.
  5. Vérifiez la sauvegarde de Noxium dans Réglages › Sauvegarde iCloud.
Attention

Les photos réaffichées apparaissent dans votre photothèque principale jusqu’à ce que vous les importiez et les supprimiez. Faites-le d’un coup, sur un téléphone que vous êtes seul à utiliser.

Un coffre avec sa propre clé

Noxium s’ouvre avec un schéma que vous seul connaissez, pas avec le code de votre iPhone. Gratuit pour 150 photos, 10 vidéos et 1 coffre leurre.

Questions fréquentes

L’album Masquées est-il aussi sûr qu’une app de coffre photo?

Pas contre quelqu’un qui connaît le code de votre iPhone, parce que le code l’ouvre. Contre quelqu’un qui fait juste défiler votre téléphone, il suffit. Un coffre ajoute un code distinct et son propre chiffrement.

Quelqu’un peut-il voir mon album Masquées avec mon code?

Oui. L’album Masquées se déverrouille avec Face ID, Touch ID ou le code de l’iPhone : quiconque a le code peut l’ouvrir.

Les photos masquées se synchronisent-elles avec iCloud?

Oui, si Photos iCloud est activé. Elles restent masquées sur vos autres appareils aussi. Elles ne sont chiffrées de bout en bout dans iCloud que si vous activez la protection avancée des données.

Ai-je besoin d’une app de coffre si j’utilise la protection avancée des données?

Ça dépend de qui vous inquiète. La protection avancée des données tient Apple à l’écart de vos Photos iCloud, mais quiconque a votre code peut quand même ouvrir l’album Masquées sur le téléphone.

Les photos que je déplace dans un coffre restent-elles dans Photos iCloud?

Seulement jusqu’à ce que vous les supprimiez de Photos et vidiez Supprimées récemment. Ensuite, les seules copies sont dans le coffre et dans sa propre sauvegarde chiffrée.
