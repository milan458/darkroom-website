How to change the Hidden album password on iPhone

By Inertia Projects·Last updated 23 November 2026

Short answer

The Hidden album has no password of its own: it opens with Face ID, Touch ID or your iPhone passcode. To change its "password", change your iPhone passcode in Settings › Face ID & Passcode, then tap Expire Previous Passcode Now so the old one stops working. For a code that's separate from your passcode, use a locked note or a vault app.

People search for a Hidden album password setting because they want the album to open with something only they know. iOS doesn't offer one. This guide shows what actually controls the lock, how to change it on iPhone and Mac, and what to use if you need a code nobody else knows. For finding and using the album, see how to view hidden photos on iPhone.

Does the Hidden album have its own password?

No. Since iOS 16 the Hidden album is locked by default, and it opens with Face ID, Touch ID or your iPhone passcode (Apple: Hide photos with the Hidden album). There is no menu to give it a different code.

That means whoever knows your iPhone passcode can open your Hidden album. Changing the album's lock means changing your passcode.

How do you change the passcode that opens the Hidden album?

Change your iPhone passcode, then expire the old one. iOS 26 steps:

  1. Open Settings › Face ID & Passcode (or Touch ID & Passcode) and enter your current passcode.
  2. Tap Change Passcode and enter the current one again.
  3. Tap Passcode Options and choose Custom Alphanumeric Code or Custom Numeric Code for something longer than six digits.
  4. Enter the new passcode twice.
  5. Tap Expire Previous Passcode Now on the same screen, then confirm. Without this, the old passcode keeps working for 72 hours (Apple: Expire an old passcode sooner).

The new passcode now opens your iPhone and your Hidden album. It also opens Recently Deleted, which shares the same lock.

Watch out

Write the new passcode down somewhere safe until you know it by heart. If you forget it after expiring the old one, the only way back in is to erase the iPhone and restore from a backup.

Should you also reset Face ID?

Only if someone else's face might be enrolled. Face ID opens the Hidden album without the passcode, so an extra face is an extra key.

  1. Open Settings › Face ID & Passcode.
  2. Check for an alternate appearance. If Set Up an Alternate Appearance isn't shown, one is already set up.
  3. Tap Reset Face ID and set up your own face again if you're unsure who set it up.
  4. Leave Require Attention for Face ID on, so your face can't unlock it while you're asleep.

Can you lock the whole Photos app instead?

Yes, since iOS 18, but it uses the same passcode. Touch and hold the Photos icon on your Home Screen and tap Require Face ID. Photos then asks for Face ID every time it opens, which stops someone browsing your library on an unlocked phone. It doesn't give you a new code: if Face ID fails, your iPhone passcode opens it, just like the Hidden album.

How do you change the Hidden album password on a Mac?

On a Mac, the Hidden album opens with Touch ID or your Mac login password, so change the login password. Open System Settings › Users & Groups, click the info button next to your account, and choose Change Password. If someone else's fingerprint is set up, remove it in System Settings › Touch ID & Password.

How do you get a password that's different from your passcode?

Use something other than the Hidden album. You have three choices:

Questions people ask

Can I set a different password for the Hidden album?

No. The Hidden album uses Face ID, Touch ID or your iPhone passcode. For a separate code, use a locked note or a vault app.

Why does my old passcode still open the Hidden album?

Since iOS 17, the previous passcode works for 72 hours after a change. Tap Expire Previous Passcode Now in Settings › Face ID & Passcode to end it.

How do I turn off the Hidden album lock?

Turn off Use Face ID in Settings › Apps › Photos. We don't recommend it: the album then opens without any check, and apps with full Photos access can read hidden photos.

Does changing my passcode affect my hidden photos?

No. The photos stay hidden and in place. Only the code that opens the album changes.
