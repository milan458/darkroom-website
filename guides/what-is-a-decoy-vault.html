What is a decoy vault, and does it actually protect you?

By Inertia Projects·Published 22 October 2026·Last updated 28 November 2026

Short answer

A decoy vault is a second, harmless vault inside a photo vault app that opens with a different PIN, password or pattern. If someone pressures you to open the app, you open the decoy, and they see ordinary photos instead of your private ones. A duress or emergency erase code goes further and erases your other vaults or locks you out of them, which can't be undone on that phone. Neither is a guarantee: a decoy works best when it's believable and nothing in the app reveals that a second vault exists.

If someone makes you open the app, you open the decoy, and they see ordinary photos instead of your private ones. This guide is for anyone who might be pressured to unlock their vault, by a partner, a parent or anyone else, and wants to know how decoys, duress codes and emergency erase differ before choosing one.

Refusing to open a vault can make a tense moment worse. A decoy gives you a third option. A duress or erase code goes further and destroys data. Each one helps in a different situation, and each has limits.

How does a decoy vault work?

The app accepts more than one code. Your real code opens your real vault. A second code opens a separate vault that you've filled with ordinary photos. To anyone watching, both look like you simply opened the app.

You'll also see it called a fake PIN, decoy password, fake vault, secondary passcode or decoy account. The idea is the same, but apps build it in two very different ways:

  • A fake screen or fake gallery. The decoy code opens a different view in the same app, often with a settings menu that still shows the decoy option. Anyone who looks through settings, or knows the app, may see that a decoy exists.
  • A separate encrypted vault. Each code unlocks its own vault with its own key. The app can't list the other vaults, because it can't read them without their codes.

The second kind is much harder to see through, because nothing inside the decoy points to anything else. Listings rarely say which kind they are, so you have to test it (see the steps below). For how vault encryption and keys work in general, see how photo vault apps work.

What are a duress code and an emergency erase?

A duress code is a code you give when you're being forced to unlock something. It looks like a normal unlock but does something else. In photo vault apps, that something else usually means removing or erasing your other vaults, which is why apps also call it emergency erase, panic erase or an erase-all code.

  • Emergency erase or duress vault. A separate code opens a harmless vault and, at the same moment, deletes your other vaults or removes access to them. Your photos can't be seen, but on that phone they're gone.
  • Escape code or panic switch. These don't open a decoy or erase anything. An escape code makes the app look empty, and a panic switch jumps to another app or locks the vault, for example when you turn the phone face down. They help when someone glances at your screen, not when someone asks you to unlock. Some disguised vaults, such as Calculator#, add one; see calculator vault apps.

A decoy hides your vault; an erase code destroys it. Only set up an erase code if losing those photos is better than them being seen, and keep a copy you control somewhere else if you can't afford to lose them.

How do decoy vaults, duress codes and panic switches differ?

The main difference is what happens to your real photos when you use the code.

What each feature does when you use it
FeatureWhat the other person seesYour real photosUndo?
Decoy vaultA vault of harmless photosUntouched, still on the phoneNothing to undo
Duress code or emergency eraseA harmless vaultErased or locked away on that phoneOnly from a backup the app didn't erase
Escape code or panic switchAn empty app, or another appUntouchedNothing to undo

A decoy is the safer first choice for most people: it costs nothing if you use it by mistake. An erase code is for the rarer case where being seen is worse than losing the photos. A panic switch suits a quick glance over your shoulder.

What can't a decoy vault or duress code protect against?

A decoy buys you a calm moment; it doesn't make your real photos disappear. An erase code makes them disappear from the phone, but not from everywhere.

  • A decoy has to be believable. An empty decoy, or one with three photos, invites more questions. Put real, boring photos in it and add a few now and then.
  • It doesn't beat a determined expert. Storage use, backups or forensic tools may show there's more data than the decoy explains.
  • Face ID can give it away in apps where Face ID opens your real vault while someone watches. Use the decoy code under pressure, not Face ID.
  • Copies elsewhere aren't touched. Neither feature reaches photos still in the Photos app, Recently Deleted, iCloud Photos, chats or another phone. An erase code may also leave a cloud backup, depending on the app.
  • Someone who watched you enter your real code, or found your recovery phrase, can still open your real vault later.
  • It's not legal protection. Rules on unlocking devices, and on deleting data when asked, differ by country and situation. A decoy is a privacy tool, not advice on what you must or mustn't do.

How do you set up and test a decoy vault?

Set it up as if you'll need it tomorrow, then open it as if you were the other person. It takes a few minutes and saves a bad moment later.

  1. Pick a code you won't mix up with your real one, but can recall under stress.
  2. Fill it with real, dull photos: food, a trip, screenshots, a pet. Dozens, not three.
  3. Open the decoy with its own code, starting from a locked app.
  4. Go through every screen, settings included. Anything that names another vault, counts more items than you can see, or offers to "switch vault" is a giveaway.
  5. Check the storage and backup screens. A total far larger than the decoy's contents invites questions.
  6. Check Face ID. If it opens the real vault, practise using the decoy code instead.
  7. Use it now and then and add a few photos, so the newest items aren't months old.

If you also want an erase code, read exactly what the app says it erases, including any cloud backup, before you set one up. Never test an erase code on a vault you care about.

Questions people ask

What is a decoy vault?

A second vault in a photo vault app that opens with a different code and holds harmless photos. If someone makes you open the app, you open the decoy instead of your real vault.

Is a decoy vault the same as a duress code?

No. A decoy only opens a harmless vault and leaves your real one alone. A duress or emergency erase code also deletes your other vaults or removes access to them, which you can't undo on that phone.

Can someone tell I'm using a decoy vault?

Possibly. Apps that show the decoy option in settings, or decoys with very few photos, are easy to spot. A decoy that's a separate encrypted vault, filled with ordinary photos, is much harder to see through.

Can you have more than one decoy vault?

In some apps. Most listings we checked describe a single decoy code or account. Noxium's free plan includes 1 decoy vault.

Does the iPhone Hidden album have a decoy?

No. Apple describes one Hidden album, locked by default and opened with Face ID or Touch ID on iPhone, with no second, harmless version.
