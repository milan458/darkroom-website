Private Photo Vault 評價：和 Noxium 比一比

作者：Inertia Projects·最後更新：2026年11月26日

簡短回答

Private Photo Vault（Pic Safe）是美國 App Store 上評分數最多的保險庫，超過一百萬則，具備入侵報告、偽裝密碼和私密瀏覽器。它的加密備份 Cloud Vault 是 Premium 功能，存在開發者自家的雲端；免費版不會備份。看重功能和歷史，選它；想要免費加密備份到自己的 iCloud，而且沒有用來追蹤你的資料，選 Noxium。

Legendary Software Labs 的 Private Photo Vault 從 2011 年 2 月起在 App Store 上架。在美國有 1,019,778 則評分、4.8 顆星，是照片保險庫中最知名的名字；在台灣 App Store 也有 1,309 則評分、4.9 顆星。這篇評價根據它的 App Store 頁面（台灣價格於 2026 年 11 月 18 日查核），看它哪裡做得好、哪裡不足，再和 Noxium 比較。Noxium 是我們開發的，談到自家 App 的部分請自行斟酌。

Private Photo Vault 哪裡做得好，哪裡不足？

它的功能幾乎比任何保險庫都多，也有 15 年的歷史。不足之處在於免費能用到什麼，以及頁面對手機上的加密說了什麼。

Private Photo Vault 做得好的地方

  • 歷史悠久。2011 年起就在 App Store，至今仍在更新（30.0 版於 2026 年 11 月 12 日推出），在美國有超過一百萬人給出 4.8 顆星。
  • 鎖可以選。PIN 碼或圖形二選一，個別相簿還能另設密碼。
  • 入侵報告。頁面說會記錄入侵嘗試者的照片和 GPS 位置。Noxium 沒有這個功能。
  • 偽裝密碼和面朝下即上鎖，用在有人搶走手機或逼你打開的時候。
  • 公司讀不到的 Cloud Vault。頁面說你的 Cloud Vault 密碼從不備份到它的伺服器，而且檔案正是用這組密碼加密，所以員工看不到。
  • 額外功能：能直接存進保險庫的私密瀏覽器、無線傳輸、iTunes 同步，以及 iPad 支援。

Private Photo Vault 不足的地方

  • 免費版沒有備份。頁面寫得很清楚，並請免費用戶自己備份照片。手機一丟，保險庫也跟著不見。
  • 沒有說明手機上的加密。頁面說 Cloud Vault 有加密，但除了密碼之外，沒說存在 iPhone 上的檔案怎麼保護。
  • 是它的雲端，不是你的。Cloud Vault 的備份放在開發者那裡，由你的 Cloud Vault 密碼保護。頁面說忘了這組密碼，就看不到 Cloud Vault 的資料。
  • 追蹤。它的隱私權標籤列出用來追蹤你的資料和與你連結的資料。
  • 價格不清楚。頁面列出 NT$240–NT$1,350 的 Premium 購買項目，卻沒說哪個是哪個，另有 NT$220 的「Remove Ads」。

Private Photo Vault 和 Noxium 有什麼不同？

最大的差別是備份：Noxium 免費備份到你自己的 iCloud，Private Photo Vault 則要 Premium，而且備份到它自己的雲端。其次是各自對加密說了多少，以及各自追蹤什麼。

備份與回復

Noxium 在免費方案中就會把所有內容備份到你自己的私人 iCloud，離開手機的只有加密過的資料。在新 iPhone 上畫出圖形，保險庫就會回復；請看加密 iCloud 備份。Private Photo Vault 的 Cloud Vault 也用只有你知道的密碼加密，這點不錯，但它需要 Premium，而且放在開發者的伺服器上。

手機上的加密

Noxium 用 Argon2id 從你的圖形產生金鑰，在 iPhone 上以 AES-256-GCM 加密每張照片、每部影片和每則備忘錄。名稱、日期和地點也都加密，圖形從不儲存。Private Photo Vault 的頁面沒寫演算法，也沒說明手機上的檔案怎麼加密。這部分為什麼重要，請看裝置端加密。

鎖、偽裝與警示

兩者都有圖形鎖、偽裝和面朝下即上鎖。Private Photo Vault 另有入侵報告和個別相簿密碼。Noxium 另有相簿圖形（Pro）和緊急清除圖形（Pro），後者會打開一個無害的保險庫並清除其他保險庫。

忘記密碼

Noxium 誰都無法重設。你在設定時抄下復原短語，不論在這支 iPhone 還是新 iPhone 上，都能用它打開保險庫。Private Photo Vault 的頁面警告，忘記 Cloud Vault 密碼就會失去那些雲端資料，但沒說明 App 鎖本身怎麼找回。

價格與隱私

在台灣 App Store，Noxium Pro 每週 NT$90、每年 NT$590，或一次買斷 NT$1,290，免費方案包含 150 張照片、10 部影片和完整備份。Noxium 沒有廣告、沒有帳號、沒有分析，隱私權標籤是「未收集資料」。

該選哪一個？

  • 選 Private Photo Vault，如果你想要入侵報告、私密瀏覽器和悠久的歷史，或你的 iPhone 是 iOS 15 或 16。
  • 選 Noxium，如果你想要免費加密備份到自己的 iCloud、寫明演算法並有文件說明的手機端加密、復原短語，而且不要用來追蹤你的資料。

怎麼從 Private Photo Vault 換過來又不弄丟照片？

匯出到「照片」App，檢查副本，匯入新的保險庫，最後才刪除任何東西。頁面說 Private Photo Vault 可以從「照片」App 匯入，也能匯出到「照片」App。

  1. 先清點數量，每本相簿都算，包括另設密碼的相簿和偽裝的部分。
  2. 把每本相簿匯出到「照片」。在 Private Photo Vault 裡操作。如果你用 Cloud Vault 搭配 Space Saver，請先確認完整尺寸的原檔已在手機上。
  3. 檢查副本。在「照片」裡確認數量相符、影片能播放、照片是完整尺寸。
  4. 匯入 Noxium。打開設定 › App設定 › 提供從「照片」刪除的選項，它會詢問是否移除「照片」裡的副本。之後清空最近刪除。
  5. 檢查備份。到 Noxium 的設定 › iCloud備份確認。
  6. 確認之後，才從 Private Photo Vault 刪除，並到設定 › [你的姓名] › 訂閱項目取消 Premium。
注意

匯出的照片在新保險庫匯入之前，會以未加密的狀態留在圖庫裡。請一次搬完，並在只有你使用的手機上進行。更多說明請看搬移保險庫而不弄丟照片。

常見問題

Private Photo Vault 安全嗎？

它是歷史悠久、持續更新的 App，Cloud Vault 據公司說連它自己都讀不到。不過頁面沒有說明手機上檔案的加密，免費版沒有備份，隱私權標籤也列出用來追蹤你的資料。請看照片保險庫 App 安全嗎？

Private Photo Vault 會備份我的照片嗎？

只有 Premium 會。頁面說免費版不會備份到 Cloud Vault，並請你自己備份。

什麼是入侵報告？

頁面說明，有人用錯誤密碼試著進入時，它會記錄照片和 GPS 位置，讓你知道是誰、在哪裡嘗試。

忘記 Cloud Vault 密碼會怎樣？

頁面說你將無法查看 Cloud Vault 的資料，因為密碼從不存在它的伺服器上。請把它寫在安全的地方。

Private Photo Vault 和 Keepsafe 是同一個嗎？

不是。它們是不同公司的不同 App。我們的 Keepsafe 評價拿那一款和 Noxium 比較。
