iPhone 的「已隱藏」相簿真的私密嗎？

作者：Inertia Projects·最後更新：2026年11月13日

簡短回答

只對了一半。從 iOS 16 開始，「已隱藏」相簿預設會用 Face ID 鎖住，所以別人拿著你已解鎖的手機也打不開。但它不是獨立的保險庫：你的 iPhone 密碼就能打開它，它會同步到你 Apple 帳號底下的每一台裝置，而且在 iCloud 中，只有開啟「進階資料保護」才會端對端加密。

「已隱藏」相簿免費、iPhone 內建，所以大多數人第一個就把私密照片放進這裡。它擅長的事只有一件：讓照片不出現在主要圖庫中。至於這樣夠不夠私密，要看你想防的是誰。以下說明它能保護什麼、不能保護什麼，以及怎麼設定得更嚴格。

「已隱藏」相簿實際上做了什麼？

它讓照片從眼前消失。隱藏的照片會從圖庫、回憶和精選照片、小工具中消失，只會出現在選集 › 更多項目下方的「已隱藏」相簿裡。

從 iOS 16 開始，「已隱藏」和「最近刪除」預設為鎖定，要用 Face ID、Touch ID 或密碼才能打開（Apple：使用「已隱藏」相簿隱藏照片）。你也可以在設定 › App › 照片 › 顯示『已隱藏』相簿把整個相簿從畫面上拿掉。

它不會做的事，是移動、拷貝或重新加密照片。隱藏的照片是同一個圖庫裡的同一個檔案，只是多了一個「不要顯示」的標記。

誰看得到你隱藏的照片？

任何能用密碼解鎖你 iPhone 的人，或能解鎖另一台登入你 Apple 帳號之裝置的人，都看得到。實際情況整理如下。

誰能打開「已隱藏」相簿（iOS 26，預設設定）
情況看得到隱藏的照片嗎？
有人在滑你已解鎖的 iPhone看不到。「已隱藏」相簿會要求 Face ID。
有人知道你的 iPhone 密碼看得到。Face ID 失敗時會改用密碼。
有人在用你的 iPad 或 Mac看得到，只要對方能解鎖那台裝置，而且 iCloud 照片已開啟。
有人逼你解鎖手機看得到。沒有第二組密碼，也沒有偽裝保險庫。
擁有完整「照片」取用權的其他 App相簿鎖定時看不到。如果你關閉鎖定，擁有完整圖庫取用權的 App 就能要求讀取隱藏的照片（Apple 開發者文件，英文）。
Apple，或向 Apple 調閱你 iCloud 資料的法律要求在 iCloud 的標準資料保護下，iCloud 照片的金鑰在 Apple 手上。開啟「進階資料保護」後就不在了。

為什麼密碼是弱點

「已隱藏」相簿的 Face ID 鎖是為了方便而設的鎖，不是一道獨立的鎖。Face ID 失敗或被略過時，iPhone 密碼就能打開這個相簿。伴侶、孩子、室友常常知道這組密碼，或看過你輸入。在公共場合輸入的六位數密碼，也很容易被人從肩膀後面偷看。

如果身邊的人知道你的密碼，「已隱藏」相簿頂多讓照片不會被隨手看到，僅此而已。

隱藏的照片會同步到你的其他裝置

開啟 iCloud 照片後，你在一台裝置上隱藏的照片，在其他裝置上也會隱藏（Apple）。也就是說，每一台登入你 Apple 帳號的 iPad 和 Mac 上都有這些照片。在全家共用的 iPad，或別人也會用的 Mac 上，這一點就很重要。在 Mac 上，「已隱藏」相簿要用 Touch ID 或登入密碼打開。

「已隱藏」相簿在 iCloud 中有加密嗎？

只有開啟「進階資料保護」才會端對端加密。預設的 iCloud 照片在傳輸過程中和 Apple 伺服器上都有加密，但金鑰在 Apple 手上。開啟「進階資料保護」後，照片會改為端對端加密，金鑰只留在你信任的裝置上（Apple：iCloud 資料安全概覽）。

要開啟這項功能，請前往設定 › [你的姓名] › iCloud › 進階資料保護，並依照步驟操作。因為 Apple 之後就無法協助你復原資料，你需要先設定復原聯絡人或復原密鑰（Apple：如何開啟「iCloud 進階資料保護」）。

怎麼讓「已隱藏」相簿更私密

  1. 保持鎖定。在設定 › App › 照片中，確認使用 Face ID已開啟。這也能防止其他 App 讀取隱藏的照片。
  2. 把相簿藏起來。在同一個畫面關閉顯示『已隱藏』相簿。
  3. 換一組更強的密碼。在設定 › Face ID 與密碼 › 更改密碼 › 密碼選項中，選擇自訂英數密碼。
  4. 開啟「進階資料保護」，讓 iCloud 照片端對端加密。
  5. 確認照片還存在哪些地方：「最近刪除」、共享相簿、iCloud 共享照片圖庫、「訊息」，以及你帳號底下的每一台 Mac 或 iPad。

什麼時候「已隱藏」相簿不夠用？

當你擔心的人知道你的密碼、和你共用裝置，或可能逼你解鎖手機的時候。這時你需要一組和 iPhone 密碼分開的密碼、用只有你持有的金鑰加密，最好還能在被逼問時拿出一些無關緊要的內容。

這就是真正的照片保險庫 App 存在的原因。我們開發的 Noxium 用你在 5×5 螺栓板上畫出的圖形打開，和你的 iPhone 密碼完全分開。每一張照片都在 iPhone 上以 AES-256-GCM 加密，而第二組圖形可以打開一個放著無關緊要照片的偽裝保險庫。加密備份存在你自己的 iCloud，換新 iPhone 時只要畫出圖形就能復原。

常見問題

沒有 Face ID，別人看得到我的「已隱藏」相簿嗎？

看得到，只要對方知道你的 iPhone 密碼。「已隱藏」相簿可以用 Face ID、Touch ID 或密碼解鎖。

「已隱藏」相簿會出現在我的 Mac 和 iPad 上嗎？

如果開啟了 iCloud 照片就會。在一台裝置上隱藏的照片，在其他裝置上也會隱藏。在 Mac 上，「已隱藏」相簿預設為關閉，要用 Touch ID 或登入密碼打開。

App 看得到我隱藏的照片嗎？

「已隱藏」相簿鎖定時（預設就是鎖定）看不到。如果你在設定 › App › 照片中關閉「使用 Face ID」，擁有完整圖庫取用權的 App 就能要求讀取隱藏的照片。

「已隱藏」相簿能防 Apple 嗎？

只有開啟「進階資料保護」才能。在 iCloud 的標準資料保護下，iCloud 照片的加密金鑰在 Apple 手上。開啟「進階資料保護」後，照片會端對端加密。

關閉「顯示『已隱藏』相簿」會把隱藏的照片刪掉嗎？

不會。這個設定只是把相簿從畫面上拿掉。照片會留在圖庫裡，直到你取消隱藏或刪除它們。
